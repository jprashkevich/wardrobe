# MVP: сервис капсульного гардероба для женщин без стилиста

Рабочее ТЗ первой версии. Источник решений — обсуждение с владелицей продукта 6 октября 2026.

## Решения

| Вопрос | Решение |
|---|---|
| Для кого | Женщины без стилиста, сервис напрямую (B2C) |
| Системы типирования | Только открытые: цветотип по 12 сезонам, типажи по Кибби. Авторские методики (в т. ч. А. Баяндаровой) не используем без материалов и согласия автора |
| Роль ИИ | ИИ типирует сам; человек в контуре — сама пользовательница (калибровка и драпировка) |
| Платформа | Веб-приложение для телефона (PWA: ярлык на главный экран, камера, загрузка из галереи) |
| Гардероб | Загрузка фото пачкой из галереи, ИИ разбирает, пользовательница правит |
| Данные | Фото лица и гардероба хранятся в аккаунте |

## Путь пользовательницы

1. **Регистрация и согласия.** Отдельное согласие на обработку фото лица. Без него типирование недоступно, гардероб — доступен.
2. **Селфи с калибровкой.** Три снимка: анфас, три четверти, крупно глаза. Дневной свет, без макияжа, белый лист бумаги в кадре. Сервис проверяет снимок до отправки в ИИ: есть ли белый лист, не пересвечен ли, нет ли сильного цветного рефлекса. Если нет — просит переснять и объясняет почему.
3. **Цветотип.** ИИ возвращает топ-3 сезона с вероятностями и признаки, по которым решал. Затем драпировка: на экране рядом с лицом пары палитр («холодная или тёплая», «глубокая или светлая», «чистая или мягкая»), пользовательница выбирает, где лицо лучше. Итог = ИИ × драпировка. Если ИИ и драпировка расходятся — ещё одна пара палитр, затем итог с пометкой уверенности.
4. **Типаж по Кибби.** Рост и короткая анкета обязательны (без роста Кибби не определяется). Фото в полный рост в простой облегающей одежде, камера на уровне талии в 2–3 м, не в зеркало. Итог — топ-3 с объяснением.
5. **Гардероб.** 20–50 фото из галереи за раз. Для каждой вещи: категория, цвет, рукав, логотип, статус «в палитре / вне палитры / нижний слой / нейтральная обувь». Вещи с уверенностью ниже 0,7 — на подтверждение. Дубли (одна вещь на двух фото) — склеить. Фото с несколькими вещами (ремни, пара обуви) — разделить.
6. **Капсула и каждый день.** Готовая часть (эта страница): образы под сценарий и погоду, план на неделю, дневник с оценкой 1–5 и пересборкой, прическа и макияж к образу.

## Что проверено на реальных данных

Слепой прогон разбора гардероба на 58 фото владелицы — см. [eval-wardrobe.md](eval-wardrobe.md). Коротко: верно распознаны 97 % вещей по категории и цвету и 96 % по статусу палитры; ошибки приходятся на вещи с низкой уверенностью, поэтому порог 0,7 «на подтверждение» ловит большую часть ошибок.

Типирование лица по зеркальным селфи при комнатном свете дало низкую уверенность (0,4 по цветотипу, 0,25 по Кибби) и разошлось с известным типом владелицы. Вывод: без калибровочного снимка, драпировки и роста автоматическое типирование выдавать нельзя.

## Данные и безопасность

- Хранение персональных данных граждан РК — на серверах в Казахстане (закон РК «О персональных данных и их защите»). Текущий хостинг tunely (Render) не подходит.
- Фото лица — шифрование при хранении, доступ только у владелицы аккаунта; команда сервиса не видит.
- Кнопка «Удалить всё» удаляет фото и результаты без корзины.
- Если ИИ-модель работает вне РК, фото на время анализа уходят за границу: прямо указать в согласии и проверить с юристом.
- Секреты (ключ ИИ) — только на сервере, в браузер не попадают.

## Пилот

3–5 подруг владелицы. На каждую — один вечер: селфи, драпировка, загрузка 30–50 вещей. Через неделю — разбор дневника.

Метрики пилота:
- время от регистрации до первого образа (цель — до 30 минут);
- доля вещей, которые пришлось править после ИИ (цель — до 15 %);
- совпадение цветотипа ИИ+драпировка с мнением живого стилиста (на пилоте — проверка выборочно);
- сколько дней из семи пользовательница открывала образ дня;
- средняя оценка образов в дневнике.

## Порядок работ

1. Скрипт разбора гардероба на модели с ключом на сервере (сейчас разбор выполнен вручную через агентов) — повторить прогон и сравнить с эталоном.
2. Прототип калибровки и драпировки: страница с камерой и парами палитр.
3. Прототип для пилота: аккаунт по ссылке-приглашению, хранение в РК.
4. Пилот, разбор, решение о полной версии.
