# Слепой прогон разбора гардероба

6 октября 2026. Проверяем, сможет ли ИИ сам разобрать гардероб по фото из галереи — без ручной разметки.

## Как проверяли

- 58 фото владелицы: вещи на кровати, комнатный свет, часть сложены или лежат вверх ногами, одно фото с пятью ремнями.
- Фото перемешаны и переименованы (`p01`…`p58`), чтобы по имени файла нельзя было угадать вещь.
- Четыре независимых ИИ-агента по 13–15 фото, у каждого только фото и инструкция модуля распознавания (цветотип «холодная зима» задан). Ручная разметка агентам недоступна.
- Эталон — ручная разметка капсулы с поправками владелицы. Для пограничных вещей допустимы несколько ответов (например, тёмно-синяя майка «тёмно-синий» или «чёрный»).

## Результат

| Что сравнивали | Верно |
|---|---|
| Категория | 60 из 62 (97 %) |
| Цвет | 60 из 62 (97 %) |
| Статус палитры (в палитре / вне / нижний слой) | 55 из 57 одиночных вещей (96 %); для ремней эталона палитры нет |

Средняя уверенность ИИ: 0,81 на верных ответах, 0,63 на ошибочных.

## Ошибки

| Вещь | Ответ ИИ | На самом деле | Уверенность |
|---|---|---|---|
| Тёмно-синий топ с фигурным краем, лежит вверх ногами | утягивающие шорты | топ с рукавом | 0,75 |
| Серая длинная юбка, сложена вдоль | брюки цвета хаки | серая юбка | 0,55 |
| Коричневый жакет с блеском | пыльно-розовый | коричневый | 0,60 |

Те же три вещи ошибочно описала и ручная разметка в первом проходе — их правила владелица. Это предел фото «на кровати при лампе», а не только ИИ.

## Что нужно в продукте

1. **Порог подтверждения 0,7.** На подтверждение уходит около 15 % вещей, и среди них 2 из 3 ошибок.
2. **Подсказка при съёмке:** вещь развернуть, не складывать, дневной свет. Все три ошибки — на сложенных вещах или при тёплом свете.
3. **Склейка дублей.** Синяя рубашка снята дважды — агенты из разных пачек описали её как две вещи. Нужен шаг поиска похожих фото.
4. **Логотипы.** Один из двух корпоративных принтов распознан как бренд. Корпоративную одежду лучше отмечать вручную одной кнопкой.
5. **Несколько вещей на фото** (ремни) — разделены верно, все пять.
