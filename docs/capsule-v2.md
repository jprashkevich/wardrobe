# Капсула 2.0: правила сборки образов

Записаны 6 октября 2026 по разговору с владелицей. Сайт берёт образы из `data.json`; эти правила проверены для каждого из 38 образов.

1. **Силуэт — одна из трёх формул:** объём внизу и собранный верх; длинная вертикаль; отмеченная талия. Мягкий объём (баллоны, широкие брюки, оверсайз-рубашка навыпуск) — только в одной зоне. Структурный жакет мягким объёмом не считается.
2. **Одна главная вещь** в каждом образе: цвет, фактура или форма. Остальные вещи её поддерживают.
3. **Цвет:** не больше двух цветовых акцентов в образе, остальное — нейтрали палитры (чёрный, белый, серый, тёмно-синий).
4. **Формальность:** вещи отличаются не больше чем на одну ступень (спорт — смарт — деловой); исключение — главная вещь, если смешение задумано.
5. **Обувь под силуэт:** острый нос к объёму внизу, грубые ботинки к прямым и узким линиям.
6. **Руки закрыты;** коричневая замша — только на обуви, ремне и сумке и только вместе.
7. **Погода:** в мороз — только с тёплым слоем (жакет, кардиган, плотное платье, кожа).
