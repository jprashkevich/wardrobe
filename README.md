# Что надеть сегодня

Подбор образов из капсульного гардероба (холодная зима, натуральный типаж) под погоду и сценарий дня.

- Погода подтягивается автоматически с Open-Meteo для Астаны или по местоположению.
- Фильтры: сценарий дня и ключевые вещи, которые точно хочется надеть.
- «Образ дня» меняется раз в сутки; отметки «надела» хранятся только в браузере.

Страница статическая: `index.html` + `data.json` + `img/`. Публикуется через GitHub Pages из ветки `main`, папка `/` (root).
